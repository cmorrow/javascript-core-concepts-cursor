Common Mistakes & Solutions

Mistake 1: Forgetting await

// ❌ Wrong - returns a Promise, not the data
async function getData() {
    const res = fetch('https://api.example.com/data');
    return res.json();  // This is a Promise, not the actual data!
}

// ✅ Correct - await waits for the promise
async function getData() {
    const res = await fetch('https://api.example.com/data');
    return await res.json();  // This is the actual data
}

Mistake 2: No try/catch

// ❌ Wrong - unhandled errors crash the app
async function getData() {
    const res = await fetch('https://api.example.com/data');
    const data = await res.json();
    return data;  // What if fetch fails?
}

// ✅ Correct - errors are caught and handled
async function getData() {
    try {
        const res = await fetch('https://api.example.com/data');
        const data = await res.json();
        return data;
    } catch (error) {
        console.error('Error:', error);
        return null;  // Return a safe default
    }
}

Mistake 3: Mixing .then() and await

// ❌ Confusing - mixing styles
async function getData() {
    const res = await fetch('https://api.example.com/data');
    res.json().then(data => {
        console.log(data);  // This is confusing!
    });
}

// ✅ Better - stick to one style
async function getData() {
    const res = await fetch('https://api.example.com/data');
    const data = await res.json();
    console.log(data);
}

Mistake 4: CORS Errors

Some APIs don't allow requests from browsers (CORS policy).

Solution: Use public APIs that allow CORS, or use a proxy server.

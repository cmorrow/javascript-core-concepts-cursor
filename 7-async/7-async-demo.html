Video 7: Asynchronous JavaScript

Joke Fetcher Demo

This demonstrates async/await with the fetch API:

  • async - Marks a function as asynchronous
  • await - Waits for a promise to complete
  • fetch - Gets data from the internet
  • try/catch - Handles errors gracefully

Waiting for a joke...

Code Explanation

// async means "this function will do things that take time"
// await means "wait here until this finishes"
document.querySelector('#fetch').addEventListener('click', async () => {
    const el = document.querySelector('#joke');
    el.textContent = 'Loading...';  // Show loading message
    
    try {
        // fetch gets data from a URL (this takes time!)
        // await means "wait for fetch to finish before continuing"
        const res = await fetch('https://official-joke-api.appspot.com/random_joke');
        
        // res.json() converts the response to JavaScript data (also takes time!)
        // await means "wait for this to finish too"
        const data = await res.json();
        
        // Now we can use the data
        el.textContent = `${data.setup} ... ${data.punchline} 😂`;
    } catch {
        // If something goes wrong (network error, etc.), show error message
        el.textContent = 'Failed to load joke 😢';
    }
});

Why Async?

Without async: The page would freeze while waiting for data.

With async: The page stays responsive - you can click buttons, scroll, etc.

Think of it like ordering food: you don't stand at the counter waiting. You sit down, and they bring it when ready!

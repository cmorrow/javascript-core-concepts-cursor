Common Mistakes & Solutions

Mistake 1: Script Before HTML

If your script runs before the HTML loads, querySelector will return null.

Solution: Put script at end of body, or use DOMContentLoaded:

document.addEventListener('DOMContentLoaded', () => {
    // Your code here - runs after HTML is loaded
});

Mistake 2: CSS Property Names

CSS uses kebab-case (background-color), but JavaScript uses camelCase (backgroundColor).

// ❌ Wrong
element.style.background-color = 'red';

// ✅ Correct
element.style.backgroundColor = 'red';

Mistake 3: innerHTML vs textContent

textContent is safer - it treats content as plain text. innerHTML can be a security risk.

// ✅ Safe - treats as text
element.textContent = userInput;

// ⚠️ Dangerous - can execute code if userInput contains HTML/JS
element.innerHTML = userInput;

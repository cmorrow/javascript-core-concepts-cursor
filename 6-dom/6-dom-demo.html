Click Counter Demo

This demonstrates the core concepts from the video:

  • querySelector - Finding elements on the page
  • textContent - Changing text
  • style - Changing appearance
  • addEventListener - Responding to clicks

Code Explanation

// DOM = Document Object Model
// It's JavaScript's way of "seeing" and "changing" the HTML page

let count = 0;  // Variable to track clicks

// querySelector finds an element by its ID (the # means ID)
// Think of it as "find the button with id='btn'"
document.querySelector('#btn').addEventListener('click', () => {
    count++;  // Add 1 to count
    
    // Find the paragraph with id='out'
    const out = document.querySelector('#out');
    
    // Change the text content
    // Template literal: if count is 1, show "time", otherwise "times"
    out.textContent = `Clicked ${count} time${count > 1 ? 's' : ''}!`;
    
    // Change the color style
    // % is modulo - gives remainder. If count is odd, remainder is 1 (truthy)
    // If count is even, remainder is 0 (falsy)
    out.style.color = count % 2 ? 'blue' : 'red';
});

// Reset button - sets count back to 0
document.querySelector('#reset').addEventListener('click', () => {
    count = 0;
    const out = document.querySelector('#out');
    out.textContent = 'Waiting...';
    out.style.color = 'black';
});
